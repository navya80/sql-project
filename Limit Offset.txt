1. Write an SQL query to retrieve the top 5 highest-paid employees from the employee table.
Answer: select name ,salary from employee order by salary desc limit 5;

2. Write an SQL query to retrieve the details of the 5 lowest-paid employees from the employee table.
Answer: select name,salary from employee order by salary asc limit 5; 

3. Write an SQL query to find the highest-paid employee from the city of 'Hyderabad'.
Answer: select name,salary from employee where city ='hyderabad' order by salary desc limit 1;

14. Write a query to display employee records in increasing order of salary, 10 records at a time, using pagination logic.
Answer:
select * from employee order by salary limit 10 offset 0;
