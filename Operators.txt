Arithmetic Operators:

1. Write a query to display employee fname, lname and annual salary from employee? 
ans: select fname, lname,12*salary as annual_salary from employee;


2. Write a query to display all departments from employee table.

select distinct department from employee;

3. Write a query to display employee fname, lname and annual salary from employee department wise? 
select fname, lname,12*salary as annual_salary from employee where department ='HR';
select fname, lname,12*salary as annual_salary from employee where department ='IT';
select fname, lname,12*salary as annual_salary from employee where department ='Sales';
select fname, lname,12*salary as annual_salary from employee where department ='Finance';
select fname, lname,12*salary as annual_salary from employee where department ='Marketing';

4. Write a query to display employee fname, lname and salary incremented by 10000 for each employee department wise?

5. Write a query to display employee fname, lname and salary in thousands from employee department wise?

6. Write a query to display employee fname, lname and salary in LPA from employee department wise?
